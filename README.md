# 📖 Overview

DeepPink AI is a modern AI-powered chat application developed using **Next.js** and **React**. The goal of this project is to provide users with a clean, responsive, and interactive chat experience while exploring AI integration and modern frontend development practices.

This project is currently under active development, and new features are being added continuously.

---

# ✨ Features

- 🤖 AI-powered conversational interface
- 💬 Real-time chat experience
- 📱 Fully responsive design
- 🎨 Modern and clean UI
- ⚡ Fast performance with Next.js
- 🔄 Component-based architecture
- 🌙 Dark mode support *(Planned)*
- 🔐 User Authentication *(In Progress)*

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/Irchika774/DeepPink-AI.git
```

## Navigate into the project

```bash
cd DeepPink-AI
```

## Install dependencies

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
