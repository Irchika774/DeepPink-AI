# DeepPink-AI

PinkSeek AI is a **DeepSeek-inspired AI web application** built with **Next.js**, designed with a **girly deep-pink aesthetic** ✨  
It focuses on a clean UI, smooth UX, and a modern chat-style interface.

---

## 🌸 Features

- 💬 AI-style chat interface (DeepSeek inspired)
- 🎀 Girly deep-pink themed UI
- ⚡ Built with Next.js (App Router)
- 🎨 Tailwind CSS styling
- 📱 Fully responsive design
- 🧩 Component-based architecture

---

## 🛠️ Tech Stack

- **Framework:** Next.js  
- **Styling:** Tailwind CSS  
- **Language:** JavaScript / TypeScript  
- **Icons:** Font Awesome / Lucide Icons  
- **UI Theme:** Deep Pink, Soft Pastels
