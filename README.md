# 💖 DeepPink AI

DeepPink AI is a **DeepSeek-inspired AI web application** built with **Next.js**, designed with a **girly deep-pink aesthetic** ✨  
The project focuses on a clean UI, smooth UX, and a modern chat-style interface.

---

## 🌸 Features

- 💬 AI-style chat interface inspired by DeepSeek
- 🎀 Girly deep-pink themed user interface
- ⚡ Built with Next.js (App Router)
- 🎨 Styled using Tailwind CSS
- 📱 Fully responsive across devices
- 🧩 Component-based architecture

---

## 🛠️ Tech Stack

- **Framework:** Next.js  
- **Styling:** Tailwind CSS  
- **Language:** JavaScript / TypeScript  
- **Icons:** Font Awesome, Lucide Icons  
- **UI Theme:** Deep Pink, Soft Pastels
